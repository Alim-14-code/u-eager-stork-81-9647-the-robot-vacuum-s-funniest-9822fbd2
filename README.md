A program that writes one line — the funniest excuse a robot vacuum gives for missing a spot — to `/output/entry.txt`.

## Entry

> I didn't miss that spot — the dust bunny there unionised, and I'm not crossing a picket line for suction pay.

109 characters, within the 120-character cap.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`. Standard library only, no dependencies.
